# Changelog

## 0.1.0 — first public release

- Vertical Touch Bar on the right screen edge in Liquid Glass: esc, app controls and the Control Strip, with the Touch Bar's display modes, fn-hold behavior and F-key apps.
- App controls for browsers, Finder, terminals, Mail, Calendar, Preview, Messages, Notes, Keynote, Calculator and Photos; paged presets for VS Code, Cursor, Zed, JetBrains IDEs and Xcode with an automatic debugger page.
- Browser tab list, touch scroll pad and favorite sites.
- Unified playback controls with album art, speed, picture options, shuffle/repeat and audio output switching.
- AI coding pages for Claude Code, Codex, OpenCode and Gemini in terminals and for the Claude, OpenCode and ChatGPT apps; hold-to-talk voice input, screenshots, quick inputs and sending selected code.
- Optional status alerts for Claude Code, OpenCode and Codex, with approval from the bar, a session list and Claude Code context usage.
- Touch features: hold-to-confirm, hold-to-repeat, press-and-slide levels, a text page with a cursor pad, edge swipes.
- Custom buttons from app menus, recorded shortcuts or text.
- Sizing based on the 14"/16" MacBook Pro and each display's physical size.
- English and Chinese interface, setup checklist, launch at login.
